# jogo dos Triângulos

![](https://i.imgur.com/pUY89N3.gif)

## Descrição:
um jogo que lhe dará a resposta se o triangulo é equilátero, isósceles ou escaleno.

### Como jogar:
o jogo te pedira o valor de 3 números e logo após sua você digitar os valores o jogo te dira se o triângulo é equilátero, isósceles ou escaleno.
